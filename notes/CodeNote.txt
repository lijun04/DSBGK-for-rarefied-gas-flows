For usual applications, only modify the following subroutines and the variables file:
- PARAMETERS specifies the flow conditions and an arbitrary voxelized geometry;
- TWALLGET   specifies the temperature at wall surfaces and inlet/outlet;
- variables  specifies the cell number and maximum number of simulated molecules.





The following notes are provided to help understand each part of the code:

variables: MNM is maximum molecular number; NCX, NCY, NCZ, MNC are indices of cell; IRELAX for selecting relaxation parameter according to viscosity or heat conductivity; IREFLE for Maxwell reflection or CLL (not ready yet); NPR for ensemble average times; NSMP_C for sampling times of cell variables; NSMP_F for sampling times of resultant force on special plates (see it in MOVE); ISMP marks if sampling takes place for each time step; NDT for current time step; other NDT_? have definitions in PARAMETERS; NPT for total ensemble times; IB(I,NNC) for the type of the I-side of the NNC cell (see discussion below); NM is the total number of simulated molecules; ICELL(N) for the cell index where the N molecule is located; OBST(NNC)=0 for void cells and OBST=1 for solid/invalid cells; SP for molecular propoerties; VISCO for viscosity; ALPHAN and ALPHAT are CLL accommodation coefficients; TIME for time moment; DT for timestep; DENS0 for initial number density; FNUM0 for the initial value of N_l in algorithm language (i.e., number of real molecules represented by each simulated molecule); VELO0 for initial flow velocity; TEMP0 for initial temperature; UWALL for speed of possible moving boundary; DENSB(I,NNC) is the effective density of the I-side of the NNC cell (required for reflection at solid wall and inlet/outlet); FNUMC(NNC) will be used to set the inital FNUM(N), namely F_l in algorithm language, for the molecule N generated inside the cell NNC; VELOB(1:3,I,NNC) and TEMPB(I,NNC) are used as the velocity and temperature boundary conditions for the I-side; CB(1:6) are the locations of the six sides of the whole domain; CG(I,NNC) is the locations of the I-side of the NNC cell and used to determine which side the molecular trajectory will first cross; NIN(I,NNC) is the recorded number flux of molecules reflected at the I-side (only for solid side) and used to determine the effective density DENSB(I,NNC); TEMP, DENS and VELO are the macroscopic quantities at each cell; TEMPA, DENSA and VELOA will store the summations of increment info and be used to update cell variables; TEMPS, DENS and VELOS are average values sampled for smooth results; SUM_NM for total number carried by molelcular variable FNUM(N); SUM_CELL for that carried by cell's DENS; SUM_INIT is the initial total number; FORCE for force exerted on special plates sampled by collecting the momentum exchange of each reflection; PP, PV, FD and FNUM are \vec x, \vec c, F_l, N_l in algorithm language as the basic molecular variables; DX_min, DY_min and DZ_min are the minimum cell sizes for possible non-uniform cells; FLUX_MEAN is used to calculate the mass flow rate averaged inside the whole domain; DRATIO for the density ratio between outlet and inlet;          

BCWALL: update the molecular velocity U(1:3) and the carried distribution function FD1 after reflection, with consideration of non-zero wall velocity VELOB(1:3, -NNC2, NNC1) of the -NNC2 side of the NNC1 cell (NNC2=0 for moving inside the current cell NNC1, NNC2>0 for the neighboring cell if moving across the sides of NNC1, NNC2=-JJ for reflecting at the JJ-side-wall of NNC1);

F2GET: update the molecular variable from FD1 to FD2 (namely F_l in algorithm language) due to intermolecular collisions along the molecular trajectory segment traveled during DTUSE (namely \Delta_k t_l in algorithm languate);

FCLLGET: this CLL boundary condition is not ready, plese use Maxwell boundary in BCWALL; 

REFLECT: skip this as it is tried for CLL but not ready;

INIT: is similar to DSMC but additionally has 1) assign FNUMC(NNC) as the initial value of new molecules generated inside the cell NNC, e.g., FNUM(NM)=FNUMC(NNC) for N_l in algorithm language as the number of real molecules represented by the newly generated molelcule NM; 2) TEMPA, DENSA, VELOA = 0 before storing the increment info during the following movement process that is used to regulate cell variables later; 3) NIN(1:6,NNC) = 0 before storing the number flux of incoming molecules towards possible solid sides of the cell NNC, which will be used to determine the effective number density for the Maxwell BC according to mass conservation; 4) initializes the effective density for solid sides of all cells by calling WALLD;

MOVE: similar to DSMC structure, for each molecule N, 1) first store molecular info using temporary variables U(1:3), X(1:3), FD1 for F_l in algorithm language, FNUM1 for N_l in algorithm language, NNC1, MX, MY, MZ for the current cell in which the molecule N is moving; 2) call PPGET to get the time fraction DTUSE used for moving inside NNC1 that will be used later to update the remaining fraction DTR, new X(1:3), next cell info NNC2 (return NNC2=-I if the I-side is solid for reflection); 3) call F2GET to get FD2 for new F_l due to collision over DTUSE and get FNUM2 for new N_l accordingly; 4) get WEIGHT (i.e., \Delta_k N_l in algorithm language) for various summations of increment info inside each cell that will be used to update cell variables; 5) for NNC2=0, which means molecule N moves only inside the current cell and doesn't encounter any interface, update molecular variables and goto 100 for the next molecule; 6) for NNC2>0, moves to the neighbouring cell NNC2 and repeat the loop at 350 for the remaining DTR; 7) otherwise NNC2<0 for the encountered side index, molecule might leave the domain through inlet/outlet, or reflect at solid wall, or reflect at symmetric side, or swap through periodic BC, then repeat the loop at 350 for the remaining DTR after reflection or swapping; 8) generate new molecules at open boundaries and let them move inwards for a random fraction of DT;    

PARAMETERS: 1) assign gas properties, flow conditions, and CB(1:6) for the locations of six sides of whole domain; 2) set an arbitrary geometry using OBST = 0 for void cells and =1 for solid/invalid cells; 3) assign IB(I,NNC) of the I-side of cell NNC to =4 for cell-cell interface, =1 for stream at inlet/outlet, =2 for solid, =3 for symmetric, =-1 for periodic and =0 for pseudo of 2D cases (valid cell will have at least a side of =1 or =4); 4) for each cell side of IB=1 or 2, we migh assign VELOB, TEMPB, DENSB as BCs to be used for newly generated molecules or molecular reflection; 5) TWALLGET returns constant TEMP0 for isothermal case, but can be modified to set temperature variation on solid wall according to cell and side indices;  

PPGET: with the above knowledge, it is now easy to understand PPGET, as discussed in MOVE;

SUM: to get some statistics for monitoring;

UPDAT: to update cell variables using the various summations of increment info collected in MOVE, the variables for those summations are reset to zero for next time step; 

WALLD: to update the effective density DENSB(I,NNC) of each solid cell side. The first option is activated and uses cell variables to determine the number flux toward the solid cell side (noise-free). The second scheme uses the actual influx NIN(I,NNC) of reflected molecules and is more accurate but very noisy (therefore inactive by default); 

Other subroutines, like ENSEMBLE, SINGLEENSEMBLE, ENTER, OUT, REMOVE, REVELC, SAMPI and SAMPLE, are similar to those used in DSMC.
